Objectif: 

On veut pouvoir supprimer une annonce.

Etapes:
- Rajouter mot de passe dans le dépot
- Un mail doit être envoyé lorsque l'annonce est mise en ligne, contenant une URL qui pointe vers une page de suppression d'annonce.
- Sur la page de suppression d'annonce, le vendeur doit mettre le mot de passe de l'annonce pour supprimer l'annonce. 

On est entrain d'implémenter incrémentalement: @documentation/event-storming/event-storming.md
